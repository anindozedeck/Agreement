# Student Attendance SMS Alerts — Project Agreement

This repository contains a sample project agreement for a small school engaging a developer to create a Python script that checks weekly attendance and sends SMS alerts to parents or guardians when a student has been absent for three or more days.

## Agreement at a glance

- **Project fee:** KES 22,000
- **Payment:** KES 11,000 deposit and KES 11,000 on delivery, before handover
- **Schedule:** Seven working days from the date the deposit clears
- **Included:** Attendance Excel file reading, weekly absence checks, automated SMS alerts, basic testing, setup instructions, and script handover
- **Not included:** SMS provider charges, changes to attendance records or the Excel format, integrations, dashboards or apps, and ongoing hosting or maintenance

See [agreement.txt](./agreement.txt) for the complete agreement, including the sample start and delivery dates, out-of-scope change terms, and sign-off lines.
